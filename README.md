# Project 01 - Sales Data Exploration

## Objetivo
Realizar un análisis exploratorio de un conjunto de datos de ventas de retail siguiendo la fase "Ask & Prepare" del proceso de Google Data Analytics.

## Herramientas utilizadas
- **Microsoft Excel:** Para exploración inicial, detección de valores nulos, evaluación de formatos y división de texto en columnas (CSV).
- **GitHub:** Para control de versiones y alojamiento del portafolio.
- **Markdown:** Para la documentación estructurada de preguntas, análisis y conclusiones.

## Actividades realizadas
- Descarga y estructuración del dataset (Retail Sales Dataset).
- Transformación de datos (Delimitación de CSV por comas).
- Exploración de calidad estructural (filas, columnas, tipos de datos).
- Formulación de preguntas de negocio (SMART).
- Documentación de hallazgos y conclusiones preliminares.

## Próximos pasos
- Limpieza exhaustiva de datos.
- Análisis descriptivo con SQL.
- Visualización de insights con Power BI / Tableau.
