# Cybersecurity Log Analytics

Proyecto de análisis de registros de autenticación utilizando Python.

## Objetivos
- Leer logs de sistemas.
- Limpiar y estructurar datos.
- Encontrar usuarios con más intentos (posibles ataques de fuerza bruta).
- Analizar errores de autenticación.
- Preparar información para futuros dashboards.

## Herramientas
- **Lenguaje:** Python, SQL
- **Librerías:** Pandas
- **Formatos:** CSV
- **Control de Versiones:** GitHub

## Resultado esperado
Un pequeño reporte con estadísticas básicas de seguridad.
